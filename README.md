# 鸡群分布与料水覆盖分析系统（Flock Scope）

浏览器内运行的白羽肉鸡平养舍分析系统：TypeScript + WebGPU，计算着色器全部手写 WGSL，
鸡舍档案、设备布局、批次、报告存 IndexedDB；三万只鸡三维实例化渲染。

## 启动

```bash
pnpm install
pnpm dev        # 开发
pnpm build      # 类型检查 + 生产构建
node scripts/selftest.ts   # 算法自测（Node，无需浏览器/GPU）
```

需要支持 WebGPU 的 Chrome/Edge（113+）。

## 六个页面

| 页面 | 能力 |
| --- | --- |
| 鸡舍档案 | 长宽、湿帘/风机位置、隔栏与门洞，平面示意 |
| 设备布置 | 料线水线按间距自动排料盘/饮水器，线高随日龄，分段停用，布局方案对比 |
| 批次管理 | 1-42 日龄批次、冷应激/漏水事件配置、出栏报告生成与 JSON/CSV 导出 |
| 分布分析 | 单帧密度/维诺占地/料水距离热力图、GPU 计时、GPU/CPU 精确解抽查 |
| 回放 | 三万只鸡三维实例化、时间轴按帧/时/天拖动、温度曲线与扎堆时点联动 |
| 设置 | 网格精度、饲养密度上限、料水距离标准、扎堆阈值 |

## 数据策略

鸡只坐标不入库。每只鸡的位置由 `(批次种子, 帧号, 鸡编号)` 确定性生成，
任意帧按需复现，6048 帧（42 天 × 144 帧）零存储成本。IndexedDB 只持久化
鸡舍、布局、批次、扎堆事件、报告和设置。

## 计算管线（src/gpu）

默认网格 0.25m，120×15m 鸡舍对应 480×60 = 28800 格。

1. **维诺图（JFA + 精确化）**
   - JFA 乒乓缓冲做跳跃泛洪，得到近似归属，site 存鸡的连续格坐标
   - 精确化阶段把全量鸡位置按 8 格边长建 CSR 空间分桶，每格自适应扩张
     桶环，按切比雪夫下界提前停止，结果与 CPU 全枚举精确维诺一致
   - 面积 = 归属格数 × 单格面积
2. **局部密度**：质量场 N×N 窗口求和，kg/m²，超饲养密度标红
3. **绕障距离场**：隔栏格标墙，四向有序 chamfer 扫描打底，再 8 邻域松弛
   到变化计数为 0，距离沿门洞绕行而非穿墙；料盘、饮水器各算一张
4. **三维渲染**：单个 ellipsoid 顶点缓冲 + 实例化 storage，单 draw call 画三万只

## 正确性验收（主人盯的第一件事）

分布分析页"GPU/CPU 抽查校验"按钮：

- 维诺：CPU 侧网格分桶全枚举精确解，逐格比对归属与每只鸡面积
- 距离：CPU 侧 Dijkstra 多源精确绕障距离，逐格比对，验收线误差 ≤ 1 个格子
- `scripts/selftest.ts` 在 Node 内对 JFA、距离场、面积守恒做 7 项断言，全部通过

## 性能验收（主人盯的第二件事）

分布分析页展示每帧 GPU 计时。维诺 + 两张距离场目标端到端 100ms 内
（含读回）。精确化用桶环把每格扫描限制在局部，避免全量 O(格×鸡)。
实际耗时取决于显卡，集显若超 100ms 可在设置把网格调到 0.5m。
